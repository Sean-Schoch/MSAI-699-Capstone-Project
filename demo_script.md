# Model Demo Script

1. Open the repository and show the README.
2. Run `python src/predict.py --text "Emergency officials report mandatory evacuation downtown; shelter open at Central High School."`.
3. Explain the prediction probability and human-review recommendation.
4. Run a non-informative example: `Prayers for everyone affected by the storm tonight.`
5. Run a borderline example: `Water is rising fast near the bridge and people are leaving the area.`
6. Close by explaining that the model supports triage and never autonomously discards crisis reports.
